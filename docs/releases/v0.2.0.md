# VibeDeck 0.2.0

รุ่นเผยแพร่แรกของแอป Android สำหรับค้นหา เล่น และแบ่งปันเกมเว็บจากชุมชน

## มีอะไรบ้าง

- Store แบบรายการเหมือน Library ใช้ไอคอนเล็กแทนภาพปกใหญ่
- ค้นหา ตัวกรองเกม คลังล่าสุด/ที่ชอบ และหน้า Detail
- เล่นผ่าน WebView เต็มจอพร้อมกันจอดับ เลือก Full Screen / Safe Area และแนวจอได้
- เพิ่มเกมจาก URL พร้อมอ่าน OG/title/description/image และแก้ไขก่อนบันทึก
- ตรวจ URL ซ้ำตั้งแต่ preview พร้อม transaction ป้องกันการสร้างเกมซ้ำ
- Google Sign-In, ดาว 1–5, คอมเมนต์แบบ paging, Share และ Report
- แยกการล็อกอินสำเร็จออกจากปัญหาบันทึกโปรไฟล์ มี retry โดยไม่เลือก Google account ซ้ำ
- คงเกมที่โหลดได้เมื่อ catalog query อีกส่วนล้มเหลว และป้องกัน request เก่าทับสถานะใหม่
- Web SDK: keep-screen-on, haptic, orientation และ Safe Area
- ธีมมืด/สว่าง และ launcher icon ครบ densities

## การติดตั้ง

ดาวน์โหลด `vibedeck-0.2.0.apk` จาก Assets แล้วติดตั้งบน Android 7.0 ขึ้นไป ตรวจ checksum ได้จากไฟล์ `.sha256`

รุ่นนี้ใช้ Release signing key ถาวร ซึ่งต่างจาก Debug builds เดิม หาก Android แจ้งลายเซ็นไม่ตรง ผู้ใช้ Debug ควรสำรองข้อมูลเกมในเครื่องก่อนเปลี่ยนรุ่น

## การตั้งค่า backend

Google Login ของ Release ต้องลงทะเบียน Release SHA-1 ใน Firebase โปรเจกต์ที่ใช้ให้ครบ พร้อมเปิด Google provider, Firestore API, ฐานข้อมูล, Rules และ indexes ดู [คู่มือ Firebase](https://github.com/bastonzam/vibedeck-android/blob/main/docs/FIREBASE_SETUP.md) และ [Release fingerprints](https://github.com/bastonzam/vibedeck-android/blob/main/docs/RELEASING.md)

## ข้อจำกัดที่ทราบ

- รูปเป็น hotlink และอาจใช้ไม่ได้ เว็บที่สร้าง OG ด้วย JavaScript อาจต้องกรอกข้อมูลเอง
- ค้นหาจาก catalog ที่โหลดแล้ว ยังไม่มี full-text search ทั้งฐานข้อมูล
- ยังไม่มี moderation dashboard หรือ SSO ข้ามเกมภายนอก
- Session/Guest progress ขึ้นกับวิธีบันทึกและอายุ session ของแต่ละเกม
- Rules Emulator tests มีชุดทดสอบให้ใน repository แต่ยังต้องรันแยกก่อนใช้ Rules กับโปรเจกต์ใหม่
